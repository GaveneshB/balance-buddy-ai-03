# 3D Companion Models Directory

Place any custom 3D model here:
- Filename: `companion.glb`
- Format: Binary glTF (`.glb`)
- Recommended: Centered at `(0, 0, 0)` with scale ~1 unit.

When `companion.glb` is present in this directory, `Mascot3DCanvas` will automatically load and display it with 360° drag-to-spin controls and studio lighting.
If `companion.glb` is absent, `Mascot3DCanvas` uses the built-in procedural 3D jelly companion.
